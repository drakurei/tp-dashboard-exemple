# tp-dashboard-exemple

Tableau de bord de tâches réalisé avec **React**, **Vite** et **React Bootstrap**.

## Fonctionnalités

- Liste de tâches par défaut affichée sous forme de cartes
- Formulaire d'ajout (titre, description, priorité, statut)
- Validation : le titre et la description sont obligatoires, message d'erreur sous le champ
- Compteurs : total, terminées, en cours
- Clic sur le statut pour passer une tâche de « En cours » à « Terminée »

## Lancer le projet

```bash
npm install
npm run dev
```
